# Roadmap

This is a new project. These are planned directions, not delivered features or
claims of adoption.

1. Collect real bug reports from small Python and JavaScript project maintainers.
2. Improve CommonMark coverage using measured false-positive examples.
3. Add opt-in configuration for monorepos and ecosystem-specific version sources.
4. Add artifact checksum verification against a trusted input manifest.
5. Explore optional, human-reviewed Codex workflows for issue triage, regression
   test suggestions and release-note drafts. The current scanner does not use an AI API.

Before each release, run the regression suite, inspect the change report, update
documentation and record actual platform results. No schedule or approval
outcome for external support programs is promised.
